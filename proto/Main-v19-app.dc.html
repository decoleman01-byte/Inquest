Card payment protection

Description

Protect stored and processed card data, and add stronger checks on higher-value payments. The agent reads these lines as the spec when it opens a pull request against this ticket.

Requirements
  1. Tokenize the card number before it is stored
  2. Require 3-D Secure for payments over $50
  3. Send suspicious payments to fraud review
  4. Lock a card after 3 failed attempts
  5. Alert security after the third failed attempt edited Nov 4
  6. Never log the full card number
  7. Add tests for the fraud checks
